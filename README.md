# Brick Break

Android arcade game written in Kotlin with a custom Canvas renderer.

## Build

GitHub Actions builds a debug APK on pushes to `main`, `master`, or `dev`, and on manual workflow dispatch. Download `BrickBreak-debug` from the workflow run's artifacts.

## Bonuses

- `×3` — creates two extra balls for each ball currently in play.
- `↔` — temporarily widens the paddle.
- `Ⅱ` — temporarily slows the game.
- `+` — adds a life, up to five.

## Controls

Move your finger horizontally to move the paddle. Tap to launch the ball or continue.
