# Brick Break

Android arcade game written in Kotlin with Canvas rendering.

## Build

GitHub Actions builds a signed release APK on pushes to `main`, `master`, or `dev`, and on manual workflow dispatch. Download `BrickBreak-release` from the workflow run artifacts.

## Levels

Seven brick layouts rotate as you progress. Some bricks on later levels need two hits.

## Bonuses

- `×3` — creates two extra balls for each ball currently in play.
- `↔` — temporarily widens the paddle.
- `Ⅱ` — temporarily slows the game.
- `+` — adds a life, up to five.

## Controls

Move your finger horizontally to move the paddle. Tap to launch the ball or continue.
